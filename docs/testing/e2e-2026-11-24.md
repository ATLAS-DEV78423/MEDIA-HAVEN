## Bugs found

1. **Old container core hangs on `library_home`** — fixed temporarily by running a fresh core binary on loopback 8080; proper fix is rebuilding the container image when network access is available.
2. **Catalog shelves disappear when TMDB throttles** — after repeated requests, `catalogBrowse` returned empty and both Home shelves vanished, reproducing the user's "empty catalog" symptom. Needs retry plus retaining the last successful catalog.
3. **Single-word misspellings get no suggestions** — the existing retry only shortens multi-word queries. Needs a bounded prefix/alternate retry or local fuzzy suggestions.
5. **Play does nothing for movies — FIXED and re-verified on installed build** — clicking a catalog card's Play added a wanted item and opened Details, but Details rendered a disabled `<span>Play</span>` (UIA ControlType.Text, not a link). Root cause: `playHref` was built only from `episodes[0]`, and movies have no episodes. Fix: movie details now falls back to `/player/${media.id}`; three tests added. Retest on installed build `9bdcf15c…`: Details exposes `Hyperlink :: Play`; clicking it opens the player and shows "Playback could not start — source unavailable: the media file is no longer under a declared root" (correct fail-closed state because a catalog title has no downloaded source yet). `Pane :: mediahaven-video-surface` confirms the embedded mpv surface exists.
6. **Real-title source search returns no candidates** — host command returned `{"items":[],"setup_required":false}`. Direct Prowlarr queries with `X-Api-Key` returned 104 rows earlier, but at retest Prowlarr health/indexers were fine while `/api/v1/search` returned 0 rows for every query (`Iron Man`, `Iron Man 2008`, `interstellar`). Our reqwest transport also failed once with "error sending request" on loopback despite `NO_PROXY` containing `127.0.0.1`. Conclusion: external indexer/service flakiness plus a transport weakness; the UI correctly shows "No candidates" rather than inventing sources. A retry/no-proxy hardening is warranted but not yet applied.
